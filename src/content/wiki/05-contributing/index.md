## The quick version

1. Open the page you want to change and click **✏️ Edit page** at the bottom. GitHub's editor opens in your browser.
2. Make your changes, check the **Preview** tab, then click **Commit changes…** and choose *Create a new branch and start a pull request*.
3. A maintainer reviews and merges it. The site redeploys automatically.

To add a page **under** an existing page, click **➕ New sub-page** on that page. GitHub opens a new file in the right folder with a starter template already filled in. Rename `new-page.md` to something descriptive (e.g. `stall-allocation.md`) and fill it in.

> [!CAUTION] This wiki is public
> Don't add personal phone numbers, private emails, contracts, invoices, or confidential financials. Link to the committee's shared drive instead.

## Writing tips

- Write for someone joining two years from now. Explain *why*, not just *what*.
- **Link to the source.** When a page records a decision, link to the minutes it came from.
- When something changes, update the existing page and bump `lastUpdated` rather than starting a new page.
- Mark unfinished pages with `status: "stub"` so others know they need help.
